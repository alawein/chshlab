# ADR-0000: Decision title

> Template. Copy this file to `docs/adr/<NNNN>-<kebab-title>.md` for each
> material technical or governance decision.

- **Status:** Proposed | Accepted | Superseded by ADR-XXXX
- **Date:** YYYY-MM-DD
- **Deciders:** maintainer names or roles

## Context

Describe the decision's constraints, evidence, and scope. Keep the record
factual and safe for public readers.

## Decision

State the chosen approach in active voice, including the affected boundaries.

## Consequences

- **Positive:** what becomes safer, clearer, or easier to maintain.
- **Negative / tradeoffs:** what remains harder or more constrained.
- **Follow-ups:** concrete work that remains, with a reference to
  `docs/DEBT.md` when it is technical debt.

## Record policy

ADR files are append-only decision history. To change a decision, add a new
record that supersedes the old one instead of rewriting prior context.
