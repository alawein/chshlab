Does Low-Efficiency Bell Testing Prove Nonlocality?

When effective detection efficiency falls below 82.8%, post-selected CHSH S > 2 no longer rules out classical explanations. We show why — with rigorous proofs, reproducible simulations, and interactive demos.

Critical Analysis

Three Arguments & Their Rebuttals

Argument 1 — Classical Bound

"CHSH S > 2 implies quantum nonlocality."

This inference is only valid under loophole-free conditions — specifically, when detection efficiency η ≥ 82.8%. Below this threshold, local hidden variable (LHV) models can produce S > 2 without any quantum entanglement.

Classical baseline (full dataset): S = 2.001, 95% CI [1.998, 2.004], 100% acceptance

A sub-threshold experiment with CHSH S > 2 does not constitute a Bell witness. The applicable bound is not S = 2 but SLHV,max(η) = 4/η − 2.

Key formula

Argument 2 — Post-Selection Inflation

"Selecting on detected coincidences preserves statistical validity."

Outcome-dependent post-selection biases the correlation estimator. By preferentially retaining correlated event pairs, a purely classical LHV dataset can be filtered to produce S approaching 4 — exceeding even the quantum Tsirelson bound.

Post-selected classical artifact: S = 3.716, 95% CI [3.714, 3.717], only 70.0% acceptance

A high S value combined with a low acceptance rate is a red flag, not a confirmation. The S value and the acceptance rate must both be reported for any meaningful inference.

Constructive bound

Argument 3 — Reporting Standards

"Reporting CHSH S is sufficient for a Bell claim."

At detection efficiency η = 70%, the LHV upper bound is SLHV,max = 4/0.70 − 2 ≈ 3.71. A post-selected S ≈ 3.7 exactly matches the classical artifact regime — making it indistinguishable from a purely classical source without additional diagnostics.

At η = 70%: S_LHV,max = 3.71 — exactly matches post-selected artifact S = 3.716

Correct Bell testing requires either η > 82.8% or explicit diagnostics: report full-dataset S, selected-dataset S, acceptance rate per setting pair, and a no-signaling check.

Mathematical Foundations

Three Theorems

The arguments above rest on three established results. Each proof sketch below follows the standard derivation; full proofs with citations are in the supplementary material.

Theorem 1

Classical CHSH Bound

For any local hidden variable theory satisfying Locality, Realism, and Freedom:

View proof sketch

Define X(λ) = A(a,λ)[B(b,λ) − B(b′,λ)] + A(a′,λ)[B(b,λ) + B(b′,λ)]. Since B outcomes are ±1, either [B(b,λ) − B(b′,λ)] = 0 and [B(b,λ) + B(b′,λ)] = ±2, or vice versa. In either case |X(λ)| ≤ 2. Integration over λ preserves the bound: S ≤ 2.

Theorem 2

Tsirelson Bound

In quantum mechanics with entangled state |Φ+⟩ and optimal local observables:

View proof sketch

The CHSH operator Ŝ2 = 4I − [A,A′] ⊗ [B,B′]. Since commutator norms satisfy ‖[A,A′]‖ ≤ 2, we get Ŝ2 ≤ 8I, so max⟨Ŝ⟩ = √8 = 2√2. Achieved with |Φ+⟩ and angles 0, π/4, π/2, 3π/4.
